# aruseijin-s-video-cracker
I made this for myself. Using FFMPEG, It takes your high quality video file and makes it worse so it could run alright in a potato. CCP approved and vibecoded. 
  Install:
 First, it depends on FFMPEG and zenity. Make sure to get them from your favorite file manager. 
 Then, to install, just either "git clone" it or download it as zip. 
 Once it has been cloned or extracted, use "chmod +x ./compress-gui.sh or ./compress-cli.sh"

   Usage:
 Using it should be easy. 
 - Write or select the destination of your source video file.
 - Choose the resolution you want to compress it to.
 - Choose your Bitrate, and other things it asks you to do.
 - Write your destination.
 - Let it rip.
Few things to note:
- This script has been vibecoded using Deepseek. And not tested well enough.
- This script was made for my 32-bit Asus EeePeeCee running Lubuntu 16.04
